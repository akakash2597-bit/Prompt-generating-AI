### Pro Prompt AI

Pro Prompt AI is a prompt engineering workbench designed to transform rough, basic prompts into precision-engineered instructions. The application collects user goals, expertise levels, tones, and formatting requirements through a structured questionnaire, outputting an annotated, high-utility blueprint using professional AI prompting techniques. 

### 🌟 Features

* **Interactive Questionnaire:** Collects goal, tone, audience, format, length, and constraints before engineering.
* **Annotated Blueprints:** Tags the specific professional prompt engineering techniques used in the output.
* **Multi-Level Engineering:** Tailors prompts based on user levels (Beginner, Intermediate, Advanced, Expert).
* **Zero Storage Data Policy:** No data is stored, and no user sign-up is required.

### 🛠️ Prompting Framework Stack

The application systematically applies basic and professional structural rules, including: 

* **Foundational Rules:** Specificity, Role-Assigning, Format Specifications, and Audience Context.
* **Professional Rules:** Few-Shot Examples, Chain-of-Thought, Explicit Constraints, Success Criteria, Delimiters, and Iterative Refinement.
